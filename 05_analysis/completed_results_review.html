INITIAL POSTERIOR → CONVERGENCE

2. Initial 17R8C는 설정된 수렴 기준을 모두 통과했습니다.

55개 자유 파라미터를 4개의 독립 chain으로 추정했습니다. 각 chain은 adaptive warmup 12,000회, kernel을 고정한 discarded settling 12,000회, 최종 보관 표본 5,000회를 수행했습니다. settling은 사전에 정한 연속 두 개의 겹치지 않는 평가 구간을 확인했고, production은 0부터 별도로 시작했습니다. 보관 표본을 사후에 잘라 내거나 thinning하여 진단을 맞추지 않았습니다.

R̂ 및 ESS는 저장된 chain에서 독립 재계산했고 원래 값과 수치 오차 수준으로 일치했습니다.

R̂는 rank-normalized split 및 folded-split 값 중 큰 값을 사용합니다. Tail ESS는 5%와 95% quantile ESS 중 작은 값입니다. 가장 작은 ordered-coordinate tail ESS는 436.5로 통과했지만, 기준 400에서 아주 멀리 떨어진 값은 아닙니다. 이 진단은 표본의 혼합과 계산 정밀도를 평가하며, 물리 파라미터가 참값에 가까운지 또는 유일한지를 판정하지 않습니다.

초기 sampler의 구성

일반 HMC, exterior-tempered proposal, conditional heat refresh, residue 처리와 보조 transport를 결합한 기존 custom kernel입니다. warmup에서 step·metric·proposal을 조정한 뒤 production 동안 고정했습니다. Metropolis 보정과 warmup/production 분리는 일반적인 MCMC 원칙이지만, 이 조합 전체를 단일한 보편적 기본 sampler로 부르는 것은 정확하지 않습니다.

수치적 건전성과 남은 한계

Production ordinary HMC 13,108회와 exterior-tempered proposal 4,880회에서 기록된 invalid/large-energy event는 0입니다. 보조 transport는 4,000회 중 25회 invalid이고 단 1회 수락되었습니다. 따라서 “모든 proposal에 오류가 없었다”거나 “transport 덕분에 성공했다”는 결론은 지원되지 않습니다.

기록된 sampler 시간은 17.53시간입니다. 이 시간에는 일부 초기화 전처리가 포함되지 않으므로 전체 pipeline의 wall-clock 시간과 동일하지 않습니다. 빠른 exterior 영역의 production 방문이 드물어, 해당 영역의 작은 posterior 확률까지 정밀하게 추정되었다고 보장할 수는 없습니다.

CONVERGENCE ≠ IDENTIFIABILITY

3. 온도를 잘 재현하는 조합은 얻었지만, 많은 개별 R·C는 넓은 분포를 가집니다.

20,000개의 retained joint draw에서 재계산한 결과, R·C 25개 중 23개는 95% credible interval 폭이 해당 median보다 크고, 18개는 97.5%/2.5% quantile 비율이 10을 넘습니다. 반대로 zone-air C는 상당히 좁게 추정되었습니다. “모든 55개 파라미터가 정확하게 결정됐다”보다 “현재 모델·prior·입력 조건의 posterior를 수렴 기준에 맞게 추정했다”가 맞는 표현입니다.

외창 두 개는 동일한 outdoor boundary를 가지며, 현재 thermal likelihood에는 두 외창의 합성 conductance가 들어갑니다. 따라서 각각의 R을 독립적으로 구분할 정보가 이 likelihood에 충분히 존재하지 않습니다. 개별 posterior는 각각의 prior와 합성 conductance 제약에 영향을 받습니다. 외벽·내벽의 같은 경계에 연결된 component들은 likelihood label symmetry도 있어 physical-label 불확실성이 분포 폭에 포함될 수 있습니다.

실제로 log(R)·log(C) 사이의 상관도 큽니다. extwall_2의 R₁–C 상관은 −0.901, floor의 R₁–R₂ 상관은 −0.707입니다. 서로 다른 조합이 비슷한 온도 응답을 만들 수 있다는 신호입니다. Training의 lighting–occupant 입력 상관도 0.956이므로 두 heat source의 allocation을 각각 분리하는 데 제한이 있을 수 있습니다. 이 상관값만으로 모든 α의 구조적 비식별성을 증명한 것은 아닙니다.

대표값은 한 개의 coherent joint draw입니다.

M₀에 채택된 값은 original labeled log posterior가 가장 높은 retained joint draw이며, 각 marginal median을 따로 골라 합친 값이 아닙니다. 보고서 부록의 median·95% interval과 실제 모델에 채택된 값은 역할이 다릅니다. IDF reference도 lumped RC의 알려진 참값이 아니라 prior의 기준 스케일입니다. 특히 R₁·R₂ 기준에는 전체 저항을 나누는 가정이 포함되므로, reference와 posterior의 차이만으로 물리값이 틀렸다고 판단할 수 없습니다.

Prior와 noise의 시간 기준

R·C prior는 physical mean = xIDF, physical SD = 2xIDF인 lognormal입니다. α는 heat source마다 8개 state에 대한 Dirichlet(1,…,1)입니다. 이번 검토는 이 prior를 재설계하거나 바꾸지 않았습니다. Noise의 저장 이름은 hour 기준이지만 likelihood는 5분이며, 상관·innovation 크기는 시간 간격에 맞게 변환됩니다.

ρ5min = ρhour1/12
σ²5min = σ²hour × (1 − ρ²5min) / (1 − ρ²hour)

Initial posterior의 5분 상관 median은 0.99590이고 innovation SD median은 0.03585°C입니다. 높은 상관은 residual이 시간에 따라 부드럽게 이어지는 모델임을 뜻합니다. 낮은 innovation SD만으로 전체 온도오차가 그만큼 작다는 뜻은 아닙니다.

ALL PAIRS → LOCAL MCMC → PASS → PARETO → REPEAT

4. 모든 pair를 다시 만들고, 각 후보마다 새 병합부를 MCMC했습니다.

처음에는 10개 envelope component에서 45개 unordered pair를 만들었습니다. 접촉 여부나 window의 host wall로 후보를 제한하지 않았습니다. 하나를 채택할 때마다 새 parent 모델에서 모든 pair를 다시 생성하고 평가했습니다. Zone-air state는 영구 유지합니다. 후보 생성, parent 연결, 고정값 보존, α 합 보존, postfit 거리, Pareto rank, winner 및 저장 모델의 일치를 165개 후보 전체에 대해 확인했습니다.

Reduction은 initial model의 55차원 joint posterior를 매번 다시 계산하지 않습니다. 이번 채택 후보의 자유 차원은 1–10개이며, four-chain adaptive random-walk Metropolis를 사용했습니다. Covariance block proposal과 coordinate proposal을 섞고, warmup 이후에는 adaptation을 멈췄습니다. Initial의 HMC kernel과 동일하지 않습니다.

빠른 계산이 의미하지 않는 것

이 결과의 convergence는 고정된 나머지 값에 조건부인 local posterior에 대한 것입니다. M₀의 전체 uncertainty나 앞선 병합의 uncertainty를 다음 단계로 전파한 joint Bayesian reduction은 아닙니다. σ·ρ도 현재 M₀ 값으로 고정했으므로 최종 residual noise 모델의 적합성까지 입증하지 않습니다.

Primary sampler는 chain당 warmup 12,000, discarded settling 12,000, retained 6,000–24,000회로 설정되어 있습니다. PASS가 하나도 없는 단계에만 사전 정의된 rescue를 수행합니다. 마지막 5R2C 후보는 첫 시도에서 bulk ESS 288.0으로 unresolved였고, 새 독립 chain을 시작한 rescue에서 bulk ESS 408.3으로 통과했습니다. 두 시도의 표본을 유리하게 합치거나 먼저 통과한 시도를 사후 선택한 결과가 아닙니다.

5R2C는 “가능한 최소 구조”입니다.

TEMPERATURE LEVELS + TRANSITIONS + BIAS

5. Variety에 대한 응답은 유지되지만, 마지막 병합에서 온도 수준 오차가 커집니다.

ACCUMULATED CANDIDATES → SUBGROUP DISCOVERY

7. PASS/FAIL 구분 규칙은 만들 수 없었고, 변화량이 작은 pair의 숫자형 규칙은 찾았습니다.

Binary subgroup의 분모는 resolved 160개이고, 이 160개가 모두 PASS입니다. FAIL이 하나도 없으므로 모든 subgroup의 PASS rate와 전체 PASS rate가 1입니다. WRAcc = coverage × (subgroup rate − overall rate)가 모두 0이 되어 no_outcome_contrast가 반환되었습니다. 이는 subgroup 코드가 실행되지 않았다는 뜻이 아닙니다. 5개 UNRESOLVED를 FAIL로 바꿔서 대비를 만드는 것은 의미를 왜곡합니다.

Numeric subgroup은 massive–massive PASS 112개를 사용했습니다. 이는 47개의 서로 다른 member-set pair, 9개 parent stage에 해당합니다. 52개의 다른 operator와 massive–massive unresolved 1개는 제외됩니다. 예측 조건에는 병합 전 parent의 R_eff·C 비율, 최소·최대 값, boundary 개수만 사용하며, target은 병합 후 d_R·d_C입니다. RMSE나 PASS를 직접 target으로 학습한 규칙이 아닙니다.

pX,i = (stage 내 평균 rank − 0.5) / stage 표본 수
score = √(nsubgroup/112) × min(0.5 − mean(pR), 0.5 − mean(pC))

각 parent stage 안에서 d_R·d_C의 percentile rank를 계산하여 단계별 규모 차이를 줄이고, 두 target의 rank가 모두 낮아지는 조건을 찾았습니다. 최소 support 10개, 최소 3개 stage, 최대 coverage 85%, 최대 2개 조건입니다. 111개의 selector로 5,210개의 one/two-condition pattern을 고려했고, 양의 점수를 갖는 eligible pattern 1,435개 중 중복 membership을 제거한 뒤 상위 30개를 보고했습니다.

설명하기 가장 쉬운 후보 규칙은 “R_eff ratio ≤4 그리고 C ratio ≤4”입니다.

E02는 16개 trial, 6개 distinct pair, 6개 stage에서 d_R 평균 46.9%, d_C 평균 43.4% 감소와 연관되었습니다. 16개 중 13개가 두 stage median보다 작았고 3개는 예외였습니다. Pareto front 1은 3개뿐이므로 이 규칙이 채택이나 PASS를 보장하지 않습니다. 같은 자료의 validation RMSE 평균은 0.402°C, stage-matched reference는 0.425°C였으며 이는 설명적 비교입니다.

“비슷한 R·C끼리 병합하면 변화량이 작다”에는 지표 정의의 영향도 있습니다.

Massive pair의 R_eff 또는 C를 X라 하면, 현재 거리 정의에는 아래 항등식이 성립합니다. 저장된 모든 해당 trial에서 직접 재계산하여 확인했습니다.

dX² = [ln(Xmerged / √(XleftXright))]² + [½ ln(Xleft/Xright)]²

두 parent가 비슷하면 두 번째 항이 자동으로 작아집니다. 따라서 이 규칙의 일부는 새로운 물리적 발견이라기보다 거리 정의 자체에 포함된 관계입니다. 그 항을 제거한 excess-distance rank에서도 E02의 평균 R/C percentile은 0.183/0.283으로 0.5보다 낮아 같은 자료 안의 연관성은 남았습니다. 다만 이 sensitivity check는 독립 검증을 대신하지 않습니다.

30개의 규칙은 독립된 30개 발견이 아닙니다. Support 합계는 998이지만 실제로 포함된 고유 trial은 58개이며, E02는 N05와 정확히 같은 trial을 포함합니다. 후보 trial 역시 같은 건물·입력·선택된 parent를 공유하고 같은 pair가 여러 stage에 나타납니다.

현재 규칙의 적절한 사용 범위

Numeric 규칙은 다음 massive-pair 시험의 우선순위를 정하는 가설로 활용할 수 있습니다. MCMC·수렴·온도오차 검사를 생략하거나 다른 건물에도 통하는 확정 규칙으로 사용해서는 안 됩니다. p-value, permutation test, multiple-testing correction, 외부 validation은 수행되지 않았습니다. Fixed-rule leave-stage-out과 equal-pair weighting은 동일 자료 sensitivity이며 재탐색을 포함한 독립 cross-validation이 아닙니다.

8. 계산은 성공적으로 완료됐으며, 남은 질문은 모델의 용도와 불확실성입니다.

질문현재 근거로 말할 수 있는 결론
이번 initial MCMC가 또 실패했는가?아니요. 설정한 physical/ordered 수렴 기준을 모두 통과했고 원자료에서 재계산한 진단과 일치합니다.
55개 파라미터가 모두 정확하고 유일하게 추정됐는가?그렇게 말할 수 없습니다. 상당수 R·C의 posterior가 넓고, 외창 개별 R은 동일 경계 합성 conductance 때문에 분리가 제한됩니다.
Variety를 고려했는가?20–28°C의 실제 온도 변화, setpoint별 오차, 전환 후 구간, 5분 ΔT를 확인했습니다. 여러 수준을 따라가지만 bias와 전환 오차는 남습니다.
Reduction loop는 제대로 반복됐는가?모든 pair를 매 단계 다시 평가했고 9회 병합했습니다. 고정/재추정 변수, Pareto 계산, 선택 및 handoff를 검증했습니다.
5R2C를 최적 모델로 확정할 수 있는가?이 모델 family에서 허용한 최소 구조입니다. 채택 경로 내 최소 validation RMSE는 14R7C이고, validation은 선택에도 사용됐습니다.
규칙을 찾았는가?Binary는 결과 대비가 없어 불가능했고 numeric 연관 규칙은 찾았습니다. 새로운 기간·excitation·reduction path로의 재현은 아직 확인하지 않았습니다.

현재 결과를 발표하거나 전달할 때는 ① convergence 통과, ② 온도 응답과 bias, ③ posterior uncertainty, ④ conditional reduction 범위를 함께 보여주는 것이 맞습니다. 추가 계산을 한다면 기존 결과를 무조건 더 오래 돌리는 것보다, 독립된 운전 조건에서 17R8C·14R7C·5R2C의 정확도와 제어 성능을 비교하는 질문이 더 명확합니다. 이 보고서는 새로운 sampler 설정이나 threshold를 제안·적용하지 않았습니다.
