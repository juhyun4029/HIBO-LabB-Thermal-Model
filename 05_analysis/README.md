# Completed-result review

Open [`completed_results_review.html`](completed_results_review.html) in a web
browser. The report is self-contained, with embedded figures and a searchable
59-row initial-parameter appendix. Its explanatory text is in Korean; numerical
tables and parameter identifiers follow the saved calculation outputs.

The report examines initial convergence, marginal uncertainty, the nine
accepted merges, temperature errors across setpoint levels and transition
periods, the final 5R2C coefficients, and subgroup findings. It distinguishes
numerical convergence from physical identification and predictive accuracy.

The report is an interpretation of the completed experiment, not a sampler
input. Curated calculation summaries are in [`../04_results/`](../04_results/).
The workflow's export and subgroup-analysis implementations are in
[`../03_workflow/`](../03_workflow/).

Some evidence labels in the report refer to intermediate files from the
completed-result review. Those labels describe the review's calculation
history; the compact parameter summaries, accepted path, convergence summaries and rules are distributed under `04_results`. Raw arrays and full candidate records are omitted from this repository.
