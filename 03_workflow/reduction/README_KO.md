# Conditional model reduction

The parent controller prepares inputs from the new initial posterior after saving its archive and checking convergence. Run the integrated calculation from the repository root with `python run.py start`.

`case5_*` input names are compatibility identifiers. Their values are generated from the current initial run; completed historical estimates are not loaded. `SCIENTIFIC_METHOD.md` defines all-pairs candidates, conditional merged-component inference, acceptance gates, Pareto selection, stopping and subgroup discovery.
